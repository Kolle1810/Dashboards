# 💑 Unser Dashboard

Ein gemeinsames Dashboard für zwei – ganz ohne Programmierkenntnisse nutzbar.
Alles steckt in **einer einzigen Datei**: `index.html`.

## Was kann das Dashboard?

| Bereich | Was es macht |
|---|---|
| **Übersicht** | Die wichtigsten Zahlen auf einen Blick: Ausgaben, wer wem etwas schuldet, offene To-dos, nächster Termin |
| **Meetings** | Themenliste fürs nächste Paar-Meeting + Protokolle vergangener Meetings |
| **Kosten** | Ausgaben eintragen (wer hat bezahlt?), Monatsübersicht mit Diagramm und automatischer 50/50-Abrechnung |
| **Kalender** | Eigene Termine mit Countdown + optional euren Google-Kalender einbinden |
| **To-dos** | Wochenaufgaben mit Zuordnung (wer macht's?) zum Abhaken |
| **Geschenke** | Geschenkideen-Listen mit „Verstecken“-Funktion für Überraschungen |
| **Projekte** | Größere Vorhaben (Urlaub, Haus …) mit Checklisten und Fortschrittsbalken |

## So startet ihr (2 Minuten)

1. Die Datei `index.html` herunterladen (oder das ganze Projekt).
2. Doppelklick auf `index.html` – sie öffnet sich im Browser. Fertig!
3. Unter **⚙️ Einstellungen** eure Namen eintragen.
4. Zum Ausprobieren: In den Einstellungen **„✨ Beispieldaten laden“** klicken.

## Wichtig zu wissen: Wo sind meine Daten?

Alle Einträge werden **nur im Browser auf dem jeweiligen Gerät** gespeichert
(im sogenannten „localStorage“). Das heißt:

- ✅ Privat – nichts landet im Internet.
- ⚠️ Handy und Laptop haben jeweils ihren **eigenen** Datenstand.

**So gleicht ihr euch ab:** Einstellungen → **„⬇️ Daten exportieren“** erzeugt
eine kleine Sicherungsdatei. Die schickt ihr euch (z. B. per Messenger), und
die andere Person liest sie mit **„⬆️ Daten importieren“** ein. Macht das am
besten regelmäßig, z. B. nach eurem Wochen-Meeting.

## Google Kalender einbinden

Die Schritt-für-Schritt-Anleitung steht direkt im Dashboard im Tab
**„Kalender“** (aufklappbarer Bereich „Anleitung“). Kurzfassung: In den
Google-Kalender-Einstellungen die Einbettungs-Adresse kopieren und im
Dashboard unter Einstellungen einfügen.

## Bonus: Das Dashboard als richtige Webseite (GitHub Pages)

Damit ihr das Dashboard über eine Internet-Adresse öffnen könnt (praktisch
fürs Handy), könnt ihr kostenlos „GitHub Pages“ aktivieren:

1. Auf github.com dieses Projekt öffnen → **Settings** → **Pages**.
2. Bei „Branch“ den Hauptzweig (`main`) auswählen und speichern.
3. Nach ein paar Minuten ist das Dashboard unter
   `https://<dein-name>.github.io/dashboards/` erreichbar.

Auch dann gilt: Die *Daten* bleiben trotzdem auf jedem Gerät lokal gespeichert –
die Webseite ist nur der bequeme Zugang.
